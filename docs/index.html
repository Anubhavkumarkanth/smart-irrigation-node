Smart Irrigation Node simulator

The control logic of an ESP32 firmware that waters a plant from a soil-moisture sensor. Dry out the soil, empty the tank or unplug the sensor and watch what the pump does. Source and firmware: github.com/Anubhavkumarkanth/smart-irrigation-node.

This is a simulation, not a recording from hardware. The soil and sensor are modelled here; the start/stop, run-time, rest-time, tank-empty and sensor-fault logic is the firmware's, ported to JavaScript.

    These two sliders are the MQTT cmd/start_below and cmd/stop_above commands. Like the firmware, they reject a start level that is not below the stop level.

    How it is modelled
    • Pump on: soil gains 1.5 percentage points per second. Pump off: soil loses 0.3 per second. These are made-up numbers so cycles are quick to watch.
    • The sensor reads 2800 mV in dry soil and 1200 mV in wet soil (placeholder calibration), plus a little noise. The reading is smoothed and checked before use, as in the firmware.
    • Fixed firmware settings: the sensor is read every 0.5 s, a single run is capped at 20 s, and the pump rests for 60 s after each run.
    • The JavaScript controller was checked against the C++ one on 30,000 random steps (including millis() wrap-around): same state, pump output and run count every step. The C++ version has 52 unit tests in the repository.
